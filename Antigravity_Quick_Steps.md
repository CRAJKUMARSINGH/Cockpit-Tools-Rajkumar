# Antigravity IDE Quick Steps - Students

## 🚀 Quick Setup (5 Minutes)

### 1. Create Your Antigravity Account
- Go to Antigravity IDE website
- Sign up with your assigned email
- Complete email verification
- Save your password

### 2. Add to Cockpit Tools
- Open Cockpit Tools
- Click "Antigravity" section
- Click "Add Account"
- Choose "OAuth Sign-in"
- Enter your email and password
- Complete authentication

### 3. Test It Works
- Find your account in dashboard
- Click "Switch"
- Click "Launch"
- Verify you're logged in to Antigravity

## 📅 Daily Use (2 Minutes)

### Start Coding:
1. Open Cockpit Tools
2. Go to Antigravity section
3. Find your account
4. Click "Switch"
5. Click "Launch"
6. Start coding in Antigravity

### Stop Coding:
1. Save your work in Antigravity
2. Close Antigravity IDE
3. Return to Cockpit Tools
4. Click "Switch" (to deselect)
5. Let next student use the PC

## ⚠️ Common Issues & Quick Fixes

### "Can't add account"
→ Create Antigravity account first, then try again

### "Wrong password"
→ Reset password on Antigravity website, then re-add to Cockpit Tools

### "Quota not showing"
→ Click "Refresh" in Cockpit Tools, wait a few minutes

### "Antigravity won't launch"
→ Check if Antigravity is installed, restart PC if needed

### "Wrong account logged in"
→ Complete the switch process, clear Antigravity cache if needed

## 💡 Pro Tips

- **Monitor your quota** - Check the dashboard before starting important work
- **Use wake-up tasks** - Set automatic quota reset reminders
- **Switch platforms** - If Antigravity quota is low, use Cursor or Windsurf
- **Save your work** - Always save before closing Antigravity
