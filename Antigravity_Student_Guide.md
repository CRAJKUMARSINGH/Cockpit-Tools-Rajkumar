# Antigravity IDE Student Guide - Cockpit Tools Integration

## What is Antigravity IDE?

Antigravity IDE is an AI-powered development environment that Cockpit Tools can manage. Students can add their Antigravity accounts to Cockpit Tools for easy switching and quota monitoring.

## Student Setup for Antigravity IDE

### Step 1: Create Antigravity Account (Before Classroom Session)

**If you don't have an Antigravity account:**
1. Visit the Antigravity IDE website or sign-up page
2. Use your assigned email address from the class list
3. Complete the registration process
4. Verify your email if required
5. Save your login credentials securely

**Your assigned email:** [Fill in your email from the class list]

### Step 2: Add Antigravity Account to Cockpit Tools (During Classroom Session)

**Process takes about 3-5 minutes:**

1. **Open Cockpit Tools**
   - Find Cockpit Tools in your system tray (bottom right corner)
   - Double-click to open the dashboard

2. **Navigate to Antigravity Section**
   - Look for "Antigravity IDE" or "Antigravity" in the dashboard
   - Click on the Antigravity section

3. **Add Your Account**
   - Click the "Add Account" button
   - Choose your preferred import method:
     - **OAuth Sign-in** (Recommended) - Sign in through Cockpit Tools
     - **Refresh Token** - If you have a refresh token
     - **Plugin Sync** - Import from existing Antigravity installation

4. **Complete Authentication**
   - **If using OAuth:**
     - Click "OAuth Sign-in"
     - Enter your Antigravity email and password
     - Complete any verification steps
     - Wait for authentication to complete
   
   - **If using Refresh Token:**
     - Paste your refresh token
     - Click "Import"
   
   - **If using Plugin Sync:**
     - Cockpit Tools will detect your existing Antigravity installation
     - Click "Import from Local"
     - Your account will be imported automatically

5. **Verify Account Added**
   - Your Antigravity account should now appear in the dashboard
   - You should see your email address and account status
   - Check that quota information is displayed

### Step 3: Test Your Antigravity Account

**Verification takes about 2 minutes:**

1. **Find Your Account** in the Cockpit Tools dashboard
2. **Click "Switch"** to activate your Antigravity account
3. **Click "Launch"** to open Antigravity IDE
4. **Verify you're logged in** with your credentials
5. **Close Antigravity IDE** and return to Cockpit Tools
6. **Click "Switch"** to deselect your account

5. **Close Cockpit Tools** (or leave it running for next student)

## Troubleshooting Antigravity Issues

### Problem: "Antigravity Account Not Adding"

**Possible Causes:**
- Incorrect email or password
- Antigravity service is down
- Network connectivity issues
- Account doesn't exist on Antigravity

**Solutions:**
1. **Verify credentials** - Double-check your email and password
2. **Check Antigravity status** - Visit Antigravity website directly
3. **Try alternative method** - Use "Plugin Sync" instead of OAuth
4. **Create account first** - Ensure you have an Antigravity account

### Problem: "Quota Not Displaying"

**Possible Causes:**
- Account not properly authenticated
- Antigravity API delay
- Network issues

**Solutions:**
1. **Refresh account** - Click "Refresh" in Cockpit Tools
2. **Re-authenticate** - Remove and re-add your account
3. **Check network** - Ensure internet connection is working
4. **Wait a few minutes** - Sometimes quota data takes time to sync

### Problem: "Antigravity IDE Won't Launch"

**Possible Causes:**
- Antigravity IDE not installed
- Wrong path configuration
- Antigravity IDE already running

**Solutions:**
1. **Verify installation** - Check Antigravity IDE is installed
2. **Check path** - Ensure Cockpit Tools has correct Antigravity path
3. **Close existing instance** - Check if Antigravity is already running
4. **Reconfigure path** - Update Antigravity path in Cockpit Tools settings

### Problem: "Wrong Account in Antigravity IDE"

**Possible Causes:**
- Account switching didn't complete
- Antigravity has cached credentials
- Session conflict

**Solutions:**
1. **Complete account switch** - Ensure switch process finished
2. **Clear Antigravity cache** - Clear Antigravity's local data
3. **Re-authenticate** - Remove and re-add your account
4. **Restart Antigravity** - Close and reopen Antigravity IDE

## Advanced Antigravity Features

### Multi-Instance Setup (For Advanced Users):

**If you need multiple Antigravity instances:**
1. **Go to Antigravity Instances section** in Cockpit Tools
2. **Click "Add Instance"**
3. **Configure instance settings:**
   - Choose different data directory
   - Set custom launch arguments
   - Bind to specific account
4. **Launch multiple instances** with different accounts

**Use Cases:**
- Work on multiple projects simultaneously
- Test with different Antigravity accounts
- Isolate development environments

### Wake-up Task Configuration:

**To optimize quota usage:**
1. **Go to Wake-up Tasks section** in Cockpit Tools
2. **Click "Add Wake-up Task"**
3. **Configure the task:**
   - Set trigger time (before quota reset)
   - Choose which account to wake up
   - Set frequency (daily, weekly)
4. **Save the task**

**Benefits:**
- Ensure quota is reset when you need it
- Avoid running out during important work
- Optimize your Antigravity usage
