### Phase 3: Cockpit Tools Setup (In-Class Session)

#### Session Structure (90 minutes):

**Introduction (10 minutes)**
- Explain Cockpit Tools purpose
- Show the dashboard interface
- Demonstrate account switching

**Setup Process (60 minutes)**
- Students add accounts one by one
- Help with authentication issues
- Test account switching

**Testing (20 minutes)**
- Each student tests their account
- Launch IDEs with their credentials
- Verify everything works

#### Setup Instructions for Students:

**Step 1: Open Cockpit Tools**
- Cockpit Tools should be running (check system tray if not visible)
- Click on the Cockpit Tools icon to open the dashboard

**Step 2: Add Your First Account**
1. Click on "Cursor" (or your preferred IDE)
2. Click "Add Account" button
3. Choose "OAuth Sign-in" (recommended)
4. Enter your email and password for Cursor
5. Complete the authentication process
6. Your account will appear in the dashboard

**Step 3: Add Additional Accounts**
Repeat Step 2 for each platform where you have an account:
- Windsurf/Devin
- Kiro IDE
- Qoder IDE
- TraeCode
- WorkBuddy

**Step 4: Test Your Account**
1. Find your account in the dashboard
2. Click "Switch" button
3. Launch the corresponding IDE
4. Verify you're logged in with your credentials
5. Close the IDE and return to Cockpit Tools

### Troubleshooting Guide

#### Common Issues and Solutions:

**Issue: "Account not found"**
- **Solution**: Student needs to create the AI IDE account first
- **Action**: Guide student to sign up on the platform website

**Issue: "Invalid credentials"**
- **Solution**: Check email/password for that specific platform
- **Action**: Student should reset password if needed

**Issue: "OAuth redirect error"**
- **Solution**: Use "Local Import" instead of OAuth
- **Action**: Import from existing installation if available

**Issue: "Quota exceeded"**
- **Solution**: Monitor usage, may need to wait for reset
- **Action**: Check dashboard for reset time, use different account

**Issue: "Account not switching"**
- **Solution**: Restart Cockpit Tools and try again
- **Action**: Check for Cockpit Tools updates

## Emergency Procedures

#### If Cockpit Tools Stops Working:
1. Restart the application
2. Check for updates
3. Restart the classroom PC
4. Contact technical support

#### If Student Cannot Access Account:
1. Verify their credentials
2. Check if the platform is down
3. Try alternative import method
4. Have them use a different platform temporarily

#### If Quota Issues Occur:
1. Check dashboard for reset times
2. Suggest using a different platform
3. Plan around peak usage times
4. Consider upgrading to paid tiers if needed
